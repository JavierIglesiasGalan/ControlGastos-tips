# ControlGastos-tips

Catálogo público de métodos y consejos de ahorro que descarga la aplicación de escritorio
**Control de Gastos** para mantener sus recomendaciones al día.

- `catalog.json` — métodos de ahorro (con reglas declarativas, sin código), consejos y novedades con
  enlace a su fuente. Esquema versión 1.
- Se actualiza periódicamente a partir de artículos de economía doméstica de fuentes fiables.
- La aplicación **solo descarga** este archivo; nunca envía datos de sus usuarios.
